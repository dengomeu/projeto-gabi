# 🚀 Projeto Lista de Amigos & Sistema de Autenticação - Gabi

Projeto desenvolvido para a disciplina de Desenvolvimento de Sistemas.

## 🛠️ Tecnologias Utilizadas
* **Back-end:** PHP
* **Base de Dados:** MySQL / phpMyAdmin
* **Servidor Local:** XAMPP / Apache
* **Front-end:** HTML5, CSS3 (Framework W3.CSS)

## 📌 Funcionalidades
- Sistema de Autenticação de Utilizador (Login)
- Controlo e Proteção de Páginas Internas via Variáveis de Sessão (`$_SESSION`)
- Módulo de Encerramento de Sessão (`Logout`)
- Gestão Completa de Registos - CRUD (Create, Read, Update, Delete) de Amigos
